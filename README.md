## 常见问题

### 原生IP和住宅IP有什么区别？

原生IP说的是IP注册地和服务器所在地一致，没被跨国二次分配。住宅IP说的是这段IP来自ISP分配给家庭用户的地址池。前者解决“地理归属对不对”，后者解决“像不像真人”。两个都满足，就是市面上说的原生住宅IP，价格也最贵。

### 英国VPS国内访问为什么慢？有什么办法？

慢的原因不在服务器本身。中国国际出口带宽不足是瓶颈，再加上国际链路拥塞和运营商出境路由限制，访问就不稳定。办法有两个：配套海外服务器加速产品，或者直接选CN2这类优化线路的机型。如果只是偶尔SSH管理，配个香港或国内的跳板机中转也行。

### 能不能先试用再买？

看商家。朝暮数据大部分云服务器支持随时销毁退款或按小时付费，这两种都能当试用，不支持的可以用测试IP测延迟和路由。CStoneCloud 支持 24 小时退款，前提是IP没被墙、没滥用。天下数据官网明确写“暂不支持直接免费试用”，测试IP要找客服要。六六云的退款政策以官网当前公示为准。

### IP被墙了能换吗？

多数商家支持更换，方式有销毁重开、更换主IP、增加IP几种，但不是每个区域都支持，要看具体参数页。要注意销毁重开可能重新分配到同一个IP，稳妥的做法是先订购新的、确认没问题再销毁旧的。

### 建站选英国还是香港？

看你面向谁。访客在欧洲和英国，选伦敦机房，本地延迟 1–3ms，欧洲全境 10–30ms。访客在国内，英国机房 150–200ms 起步，香港节点会快得多。做外贸站面向欧美客户，英国机房是对的选择；做面向国内用户的站，别为难自己。
